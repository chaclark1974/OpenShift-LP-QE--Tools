# AI History Log
This file records only **major updates and architectural/breaking changes** in
this directory and its sub-directories. Routine fixes, small adjustments, CI

records everything in full detail.

## 2026-10-07
- Adopt the `PROW_AN__<CATEGORY>__<FIELD>` env-var naming convention for all bot settings — the `PROW_AN__` app prefix and a double-underscore (`__`) separating category from field; multi-word fields inside one category use a single underscore (e.g. `PROW_AN__SLACK__BOT_TOKEN`, `PROW_AN__MONITORED_CHANNELS`, `PROW_AN__ALLOWED_BOT_IDS`). MCP connection settings group under the `MCP` category with a trailing `SHIP_HELP` qualifier: `PROW_AN__MCP__URL__SHIP_HELP`, `PROW_AN__MCP__TOKEN__SHIP_HELP`, `PROW_AN__MCP__SHIP_HELP__DEBUG`, `PROW_AN__MCP__TIMEOUT_SEC` (breaking: the deployment manifest and the live environment must follow). Only `TLS_INSECURE_SKIP_VERIFY` stays unprefixed for the bot, because the shared `pkg/analyzer` reads it bare; the CLI keeps its own unprefixed names (`SHIP_HELP_MCP_URL`, `SHIP_HELP_MCP_TOKEN`, `MCP_DEBUG`, `MCP_TIMEOUT_SECONDS`).
